Senior/staff-level engineer at Remitly. Also builds personal projects (personal finance dashboard, other side projects).

**Primary stack:** TypeScript, Next.js, React, SQLite (better-sqlite3), yarn. Also touches Go and other stacks at work.

**Code style preferences:**
- Sparse comments: only when the WHY is non-obvious. Never restate what variable names already say.
- No multi-paragraph docstrings or multi-line comment blocks.
- No trailing summaries after changes — they can read the diff.
- Prefers terse, direct responses over exhaustive explanations.

**Commit style:** Imperative mood, focus on why not what, Co-Authored-By trailer. Uses HEREDOC format for multi-line messages.

**Tooling:** Uses gh CLI, Jira, Slack. Has Claude Code hooks for TypeScript checking post-edit and pre-push gating.

**Review preference:** Care about correctness and architecture. Don't nitpick style a linter would catch. One comment per issue.
